Network

เชื่อมต่ออินเทอร์เน็ตไม่ได้

ตรวจสอบสาเหตุเมื่อคอมพิวเตอร์ไม่สามารถเชื่อมต่ออินเทอร์เน็ตได้

Network

Wi-Fi ไม่พบเครือข่าย

คอมพิวเตอร์ไม่พบชื่อ Wi-Fi หรือไม่สามารถค้นหาเครือข่ายได้

Network

Wi-Fi หลุดบ่อย

การเชื่อมต่อ Wi-Fi ขาดหายหรือหลุดระหว่างใช้งาน

Network

อินเทอร์เน็ตช้า

ความเร็วอินเทอร์เน็ตต่ำกว่าปกติหรือเว็บไซต์โหลดช้า

Network

LAN ใช้งานไม่ได้

เชื่อมต่อสาย LAN แล้วไม่สามารถใช้งานเครือข่ายได้

Network

Network Adapter ไม่ทำงาน

Network Adapter ของคอมพิวเตอร์ไม่สามารถเชื่อมต่อเครือข่ายได้

Network

DNS ทำงานผิดปกติ

ไม่สามารถเข้าถึงเว็บไซต์หรือระบบแจ้งปัญหา DNS

Network

IP Address ผิดปกติ

คอมพิวเตอร์ได้รับ IP Address ไม่ถูกต้องหรือไม่สามารถเชื่อมต่อได้

Network

Firewall บล็อกอินเทอร์เน็ต

Firewall อาจบล็อกโปรแกรมหรือการเชื่อมต่ออินเทอร์เน็ต

Network

แชร์ไฟล์ใน Network ไม่ได้

ไม่สามารถแชร์หรือเข้าถึงไฟล์จากคอมพิวเตอร์ในเครือข่ายได้

Network

มองไม่เห็นคอมพิวเตอร์ใน Network

คอมพิวเตอร์ในเครือข่ายไม่แสดงหรือไม่สามารถค้นหาเครื่องอื่นได้

Network

Network เชื่อมต่อแล้วแต่ใช้งานไม่ได้

แสดงสถานะเชื่อมต่อแล้วแต่ไม่สามารถใช้งานอินเทอร์เน็ตได้
